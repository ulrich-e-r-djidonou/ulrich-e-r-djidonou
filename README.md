**Tableaux de bord et analyses**

- [ICIE Canada](https://djidonou.com/icie-dashboard/) : indice canadien d'incertitude économique construit à partir de Google Trends.
- [GeoEcon Pulse](https://djidonou.com/geoecon-pulse/) : veille géoéconomique sur le Canada, les États-Unis, la Chine, l'Inde et le reste du monde.
- [Leave Network Explorer](https://djidonou.com/leave-network-explorer/) : visualisation des politiques de congés parentaux.
- [bdc-fedspeak](https://github.com/ulrich-e-r-djidonou/bdc-fedspeak) : indice du ton des communiqués de la Banque du Canada.
- [gravity-model-canada](https://github.com/ulrich-e-r-djidonou/gravity-model-canada) : modèle de gravité des exportations canadiennes.
- [forecasting-chomage-canada](https://github.com/ulrich-e-r-djidonou/forecasting-chomage-canada) : prévision du taux de chômage canadien, ARIMA comparé à Prophet.
